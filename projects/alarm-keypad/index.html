Why build a dedicated Alarmo keypad?

A physical 4×4 keypad makes it possible to enter a PIN and control Home Assistant Alarmo without navigating a tablet dashboard. The design uses an ESP32-C3 Super Mini, SSD1306 128×64 OLED and buzzer for status and audible feedback.

Keypad functions

The documented key map uses * to delete the last digit, C to clear, A held to arm, B held to arm in night mode, and D to submit a PIN for disarming. Behavior depends on the installed ESPHome configuration and Home Assistant automations.

Wiring, firmware and automations

The project supports an original hand-wired prototype and a cleaner custom PCB. Its Home Assistant example automations read the entered PIN from trigger.event.data.code; configure your own device and entity IDs, protect PINs and test alarm behavior carefully.

Custom PCB and 3D-printed case

The PCB reduces point-to-point wiring between the ESP32-C3, keypad, display and buzzer. The printed enclosure makes the keypad suitable for wall mounting; the original prototype and the newer finished design are both documented.

Build files and licensing

The repository contains the PCB and 3D Print folders along with firmware, examples and licensing. Software is listed as MIT; original hardware and functional printable designs as CERN-OHL-W-2.0.
